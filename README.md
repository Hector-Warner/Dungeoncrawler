# Dungeoncrawler
- An early stage project
- Will eventually be a story based game with a procedurally generated non-linear narrative
- Paths are generated randomly currently that give a small speed boost
- Terrain is generated as well randomly such as lakes and desert grass
- Signs have been implemented so that in runtime a sign can be created easily
